# موتور بازی‌سازی BDFR هامون

**[🇬🇧 English](README.md#english) | 🇮🇷 فارسی**

> **یک موتور بازی‌سازی مدرن و مقیاس‌پذیر برای جهان‌های بزرگ، رندرینگ پربازده و ساخت بصری گیم‌پلی.**

**BDFR Hamun Engine** پروژه‌ای آزمایشی برای ساخت یک موتور بازی‌سازی نسل جدید است که بر جهان‌های باز گسترده، رابط‌های گرافیکی سطح پایین، معماری ماژولار و اسکریپت‌نویسی بصری مبتنی بر گره تمرکز دارد.

وضعیت پروژه: پیش‌آلفا؛ زیرساخت رابط سخت‌افزار رندر (RHI) در حال توسعه است.

## چرا «هامون»؟

«هامون» نامی پیوندخورده با جغرافیا و هویت منطقهٔ سیستان و بلوچستان و پهنه‌های طبیعی و دریاچه‌های آن است. این نام، هدف پروژه را برای ساخت جهان‌های بزرگ، محیط‌های باز و آزادی در مقیاس توسعه بازتاب می‌دهد.

## چشم‌انداز پروژه

هدف هامون، ساخت موتوری ماژولار برای بازی‌های سه‌بعدی کوچک تا جهان‌های باز بسیار بزرگ و پیوسته است.

اهداف اصلی:

- بارگذاری و جریان‌دهی جهان‌های باز بزرگ
- پشتیبانی از رابط‌های گرافیکی مدرن
- اجرای چندریسمانی و پربازده
- رندرینگ مبتنی بر GPU
- رندرر مقیاس‌پذیر برای رایانه و دستگاه‌های همراه
- اسکریپت‌نویسی بصری یکپارچه
- سامانه‌های ماژولار فیزیک، هوش مصنوعی، صدا، شبکه و انیمیشن
- خط لولهٔ داده‌محور دارایی‌ها
- معماری افزونه‌پذیر
- گردش‌کار توسعه با محوریت ادیتور
- دارایی‌های سازگار با کنترل نسخه
- پشتیبانی بلندمدت از جهان‌های بزرگ و جابه‌جایی سریع

### ساخت اندروید

در ویندوز:
```bat
BuildAndroid.bat
```

برای ساخت، نصب و اجرا روی دستگاه متصل:
```bat
BuildAndroid.bat --install
```

خروجی اولیه در مسیر `dist/android/HamunGame-debug.apk` قرار می‌گیرد. وضعیت فعلی، راه‌اندازی بومی موتور را اعتبارسنجی می‌کند؛ رندر سطح اندروید در مرحلهٔ گرافیکی مربوط تکمیل خواهد شد.

## رابط‌های گرافیکی

| رابط | وضعیت |
|---|---|
| DirectX 12 | رابط اصلی ویندوز |
| DirectX 11 | مسیر سازگاری ویندوز |
| Vulkan | هدف اصلی چندسکویی |
| OpenGL ES | سازگاری و دستگاه‌های همراه |
| Metal | برنامه‌ریزی‌شده برای دستگاه‌های اپل |
| رابط کنسول‌ها | برنامه‌ریزی‌شده، با استفاده از SDK رسمی |
